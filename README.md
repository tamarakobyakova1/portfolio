# Tamara Kobiakova — Portfolio Template

Simple Vite + React template intended for GitHub Pages.

Quick start

1. Install dependencies:

```bash
npm install
```

2. Start dev server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

4. Deploy to GitHub Pages (update `homepage` in `package.json` first):

```bash
npm run deploy
```

Files of interest:
- [package.json](package.json)
- [index.html](index.html)
- [src/main.jsx](src/main.jsx)
- [src/App.jsx](src/App.jsx)
- [src/styles.css](src/styles.css)

Notes
- Replace `<GITHUB_USERNAME>` and `<REPO_NAME>` in `package.json` `homepage` before deploying.
- This is a minimal starter; customise layout and content as desired.
